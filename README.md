## How to use this repository

1. Start with Domain 1 and progress through Domain 6.
2. Review the domain objectives and topic summaries.
3. Relate the concepts to enterprise AI architectures and security operations.
4. Practise the scenario-based questions and revision exercises included in each document.
5. Use the official ISC2 exam outline and certification page to confirm the current exam scope and program updates.
